编辑文字后，选择颜色和质感，点击“开始展示”。轻点展示画面，即可呼出暂停和退出按钮。

这是 GitHub Pages 网页版，可直接在 iPad Safari 或任意浏览器打开。

支持常亮的浏览器会自动请求保持屏幕唤醒。如仍会自动锁屏，请在“设置 → 显示与亮度 → 自动锁定”中选择“永不”。

画面亮度调整只影响灯牌画面；屏幕背光请在 iPad 控制中心调整。灯牌文字只保存在这台设备，不会上传。

键盘：F 开始展示，空格暂停或继续动效，Escape 退出展示或关闭弹窗。系统开启“减少动态效果”时会停用滚动和呼吸动画。
